# Mapdln 2.6 · 可视化地图下载器

致谢：@nings在群里提供的Python源码，此程序基于核心Python源码开发

本程序开发目的为了适配ALIGNMENT : An Engineering Odyssey Demo中的“自由创造”板块开发，方便玩家下载高程与地形图

**双击 `mapdln.exe` 直接进入 GUI，无需安装 Python、Qt 或 GDAL。** 本工具在 [NingsingM/mapdln](https://github.com/NingsingM/mapdln) 的卫星与地形下载功能基础上增加图形界面，并统一 GUI / CLI 下载引擎。

[下载 Windows 2.4.0](https://github.com/fredqin2006-X/Mapdln/releases/tag/v2.4.0) · [开源仓库](https://github.com/fredqin2006-X/Mapdln) · [发行说明](RELEASE-NOTES.md)

当前源码版本为 **2.6.0**，本次为本地构建，尚未发布 GitHub Release。已有公开版本仍为 [2.4.0](https://github.com/fredqin2006-X/Mapdln/releases/tag/v2.4.0)。程序及交付包不携带开发者账户配置，使用在线服务时请填写自己的凭据。

## 使用

1. 解压交付 ZIP 后双击 `mapdln.exe`。单文件版首次启动需解压运行库到 Windows 临时目录，通常等待几秒。
2. 在“地图与输出”选择导出影像，点击“管理图源”配置 Mapbox、天地图、腾讯兼容影像、吉林一号，或添加自定义 XYZ / TMS / WMTS。Mapbox 使用 `pk.` 公共 Token，天地图使用自己的 Key，吉林一号填写访问 TK 与图层 MK；凭据按选中的图源检查。“仅高程”不需要影像图源凭据。
3. 按需配置高德 Web 端（JS API）Key + `securityJsCode`，或百度浏览器端 AK。高德为默认预览；也可切换 Mapbox 卫星预览。每个平台提供获取步骤、官方入口和主动连接测试。Mapbox 连接测试发起 **1 次** 瓦片请求，测试前按钮明确标注消耗。
4. 回到工作台，绘制矩形、圆形、多边形或插值曲线；也可展开左侧“高级设置”，在两列坐标表单中输入 WGS84 中心坐标和米制尺寸后定位。多边形和曲线随鼠标显示闭合预览，逐点点击后按 `Enter`（含数字键盘 Enter）或“完成”闭合，只提交已点击的点，至少需要三点；`Esc` 取消本次绘制，`Delete` 删除当前图形和草稿。白色控制点可拖动，拖动选区可移动；矩形顶部绿色 `↻` 手柄可旋转，按住 `Shift` 按 15° 对齐，缩放和移动后保留角度。双击多边形/曲线面内可增加最近边上的控制点；右键只删除控制点，不闭合图形，创建过程中可删草稿点，完成后至少保留三点。
5. 默认输出 1 米/像素，影像层级可自动推荐或手动指定。高程支持平坦 0 米、在线 FABDEM、本地 DEM；查看预计新增请求、缓存与资源消耗，选择输出位置后开始导出。

## 图源与本地 DEM

“导出影像”决定成果来源，“预览底图”可跟随导出图源，也可单独使用高德、百度或 Mapbox 定位。更换预览保留选区；正在执行的任务固定使用启动时的图源、凭据和选区快照。天地图内置 `img_w` 影像，不叠加地名注记。腾讯提供可编辑服务地址的兼容适配，默认处理 TMS 行号、16 张分组路径及 GCJ-02 坐标；该兼容接口没有官方批量下载 API 的稳定性承诺，请按服务权限使用。

吉林一号预设为 `getMap` 服务，使用 `sch=wmts` 左上原点、0–18 级、256 像素，支持 JPEG / PNG / WebP。打开图源管理选择“吉林一号”，填入自己的 TK、MK 即可；也可粘贴完整获配地址，保留企业 `pro` 参数。普通 TMS 地址应选择“TMS · 反向行号”，`{-y}` / `{reverseY}` 会自动规范化。腾讯、吉林一号的地址、层级和坐标基准可按实际授权服务调整。

自定义图源支持 XYZ / TMS（`{z}/{x}/{y}`、可选 `{s}` 子域、`{x16}/{y16}` 分组）及读取 WMTS 能力文档选择图层。支持标准 Web Mercator 全球矩阵、256 / 512 像素 JPEG / PNG / WebP，保留任意 WMTS 矩阵标识；不支持局部偏移矩阵、经纬度矩阵、矢量瓦片或 BD-09 影像导出。GCJ-02 影像按目标像素反向采样，近似校正到与 DEM 一致的米制网格；本地转换与源数据定位精度限制仍然适用，不用于测量级定位。原有透明度会保留。服务地址中的常见密钥参数（包括 TK / MK）和请求头进入加密凭据库，分享配置不携带凭据。连接测试主动请求 1 张当前位置瓦片。

选择“本地 DEM”后可选择或拖入一个有地理参考的单波段 GeoTIFF（`.tif` / `.tiff`），查看覆盖范围并定位。程序读取原始分辨率、CRS、NoData、波段 scale / offset；高程单位不明确时需选择米或英尺。水平重投影不会自动修正未知的垂直基准。任务在请求影像前逐块检查 DEM 是否覆盖选区及内部缺失值，文件在选择后变化需重新选择；不会自动补零或混入 FABDEM。仅高程 + 本地 DEM / 平坦 0 米完全不需要网络，在线 FABDEM 仍会联网。

滚轮在选区内、控制点上和绘制过程中均可缩放地图；按住滚轮中键拖动可平移地图，保留选区和已点击的草稿点。左键拖动选区用于移动选区，中键用于移动地图。

开始下载后选区变灰并锁定，绘图按钮、控制点、旋转、清除、Delete、Enter 闭合、右键删点及坐标应用暂停使用；暂停下载、等待预算和切换预览底图时保持锁定。地图仍可缩放和平移。取消任务待后台退出后解锁，下载完成后自动解锁；后台启动失败或异常退出也会解除锁定。实际导出使用开始时的选区快照，旋转矩形的轮廓和掩膜保留旋转角度，输出仍使用统一的北向米制网格。快捷键需在地图获得焦点时使用。

左侧为任务、地图与输出、额度预判卡片；任务进度、暂停/继续/取消和“开始下载”位于地图下方的任务栏，地图保持主要面积。账户配置按两列卡片排列，凭据与额度字段也并排显示，教程按需展开。详细坐标、代理、并发、重试、超时、位深、平滑和日志收在高级设置中，参数使用两列布局。数值可直接输入或用键盘调整，取消鼠标上下箭头；表单失焦时滚轮用于页面滚动。

账户页面切换保留选区和任务状态，后台任务继续运行，并固定使用启动时的参数和凭据。默认 0 米模式便于先获取影像；真实地形失败后点“改用 0 米继续导出”，有效卫星缓存无需重新下载。应用使用折叠地图、定位标记和向下箭头组合图标；可编辑原稿位于 `mapdln/assets/app.svg`，构建时自动生成多尺寸 ICO 和 PNG。

## 成果

每个任务独立目录包含：

| 文件 | 内容 |
|---|---|
| `satellite.png` | 真实形状外透明的 RGBA 影像，保留来源透明度；仅高程任务不生成 |
| `height.png` | 8/16 位高度 PNG，默认 16 位；0 米模式全部为黑色 |
| `dem.tif` | 实际高程（米）、投影和 NoData；有效的 0 米不作为 NoData |
| `mask.png` | 选区有效轮廓，内 255 / 外 0 |
| `boundary.geojson` | WGS84 边界；曲线保存采样后的闭合面 |
| `metadata.json` | 分辨率、网格变换、尺寸、编码范围、原始控制点、插值方式、图源、高程来源与请求数，不含凭据 |
| `task.log` | 已遮蔽凭据的结构化任务日志 |

PNG 旁的 `.aux.xml` 保存相同地理参考；需要地理定位时请一并保留。卫星、高度、掩膜和 GeoTIFF 逐像素对齐。高度 PNG 使用元数据中的最小/最大值线性编码，实际未平滑高程以 GeoTIFF 为准；选区外以独立掩膜区分。

## 坐标、额度和网络

- 高德 GCJ-02、百度 BD-09 选区通过本地近似算法转换为 WGS84；可直接输入 WGS84 或使用 Mapbox 预览。局部输出使用 UTM 投影，网格按指定分辨率向外对齐，不改变分辨率来凑整像素。
- 1 米输出网格不表示 1 米定位精度或原始数据精度。FABDEM 原始约 30 米，重采样不会增加真实地形细节；投影尺度因子保存在元数据中。当前支持局部选区，单边最多 100 km、1 亿像素、候选瓦片最多 10 万张，不支持跨日期变更线和极区任务。
- 瓦片数量按形状相交及重采样边缘规划。标准 Mapbox 复用旧版 JPEG 缓存；其他来源按图源配置、图层、矩阵、格式、尺寸与凭据指纹隔离。瓦片按尺寸/编码完整性检查；过期或损坏缓存重新下载，默认有效期 12 小时。
- 本机记录分开统计下载、预览、验证与重试。账户余额由手动录入的控制台用量估算，无法自动查询全账户实时余额，也不会显示未经核实的费用。高德/百度预览不消耗 Mapbox 请求；Mapbox 预览按实际请求记录，可复用有效缓存。
- 任务预算限制该任务实际影像请求，预览、验证和重试按图源分别记录。达到预算暂停，可提高预算后继续；取消保留完整缓存与已导出成果。预算不是账户级消费上限；图源失败不会自动切换到另一来源混合导出。
- 卫星下载先完成，地形随后处理。FABDEM 用带 ETag/Last-Modified 校验的 HTTP Range 读取压缩包，分块断点缓存；服务器/代理不支持 Range 时明确失败，可更换代理或选择 0 米模式。0 米模式完全不访问 FABDEM。
- 暂停不再发起新请求；卫星当前 HTTP 请求可能继续到结束，地形在传输/处理检查点停下。继续复用完整缓存；没有断点支持的当前请求重试。取消/关闭程序留下 `.part` 文件，不将其当完整缓存。
- 代理填写 `http://主机:端口` 或 `socks5://主机:端口`，仅本次会话使用。应用后分别测试 Qt 预览和 Python 下载网络；正在执行的任务仍用原快照。下载未设置显式代理时遵循 Requests 的环境代理设置，Qt 预览初始为直连。

## 本机配置

凭据存于 `%LOCALAPPDATA%\Mapdln\config.json`，通过当前 Windows 用户 DPAPI 加密；自定义图源 Token 和请求头同样加密。缓存和请求记录也在该目录。程序目录和发布包不含测试凭据。复制 EXE 给其他人不会携带当前用户配置。删除平台配置不删除下载成果。

交付版面向 Windows 10 / 11 x64。EXE 可复制到其他目录运行，不依赖工程目录或当前工作目录；地图页面和地理运行库从程序自身的临时解包目录读取。默认输出使用当前用户的系统“下载”目录，支持系统重定向；也可自行选择输出文件夹。其他用户首次运行需在账户配置页填写自己的凭据。

预览服务仅绑定 `127.0.0.1`，优先端口 8765，被占用时使用空闲端口。页面与高德转发路由包含每次启动的随机访问标识，转发验证 Host 和本机页面来源，仅允许指定官方服务。高德 `_AMapService` 保持一级路由，符合 SDK 安全模式要求；安全密钥只在 Python 转发时注入。账户页提供本次实际地址，可复制到平台限制设置；不要默认使用无限制白名单。

## CLI 与开发

CLI 与 GUI 使用同一引擎。Token 使用用户加密配置，或 `MAPBOX_TOKEN` 环境变量，**不通过明文命令行参数传递**。

```powershell
.\mapdln.exe --cli --lon 121.58901 --lat 31.2592 -w 200 -g 200 -z 17 --elevation flat --resolution 1 --output D:\地图 --name 金桥

# 使用已保存的天地图 Key，自动选择影像层级
.\mapdln.exe --cli --source tianditu --lon 121.58901 --lat 31.2592 -w 200 -g 200 -z auto --elevation flat --output D:\地图 --name 天地图

# 仅裁切本地高程；无需配置 Mapbox 或其他在线凭据
.\mapdln.exe --cli --elevation-only --dem D:\数据\地形.tif --dem-unit m --lon 121.58901 --lat 31.2592 -w 200 -g 200 --output D:\地图 --name 本地高程
```

旧 `--lon/--lat/-w/-g/-z/-m/-p/-n/-b/-s` 参数保留；`--mode tile` 对应卫星 + 0 米输出。`--token` 被移除，旧文件命名/输出模式改为统一任务目录。`--selection` 读取 `shape`、`system`、`points` 等选区 JSON，支持多边形/曲线。矩形可增加 `angle_deg`（投影平面内逆时针角度，缺省为 0），配合中心及 `width_m` / `height_m` 或旋转后的两个对角点使用。CLI 达到预算会取消并保留缓存；GUI 可交互提高预算继续。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -m pytest -q
powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

构建为单文件窗口程序，含 Qt WebEngine、Rasterio 的 GDAL、PROJ 和本机地图页面。`tools/mapdln.spec` 是唯一打包规则，根目录 `Mapdln.spec` 仅兼容转发；它过滤 Poppler ICU 冲突库与未用 Qt 资源。构建脚本验证成品版本、包内资源及独立目录后台导出后，备份旧根目录 EXE，自动将 `dist/mapdln.exe` 同步到根目录，并核对哈希。2.3.0 本机实测为 175.74 MiB，比原根目录文件减少 40.2%，详情见 [体积记录](OPTIMIZATION.md)。EXE 与交付 ZIP 作为构建成果独立保存，Git 提交保存可重现源码。源码仍保持 MIT 协议，第三方组件及地图数据遵循各自许可（见 `THIRD-PARTY.md`）。

源码入口、键鼠操作、下载锁定、回归验证、构建打包、Git 回档和故障排查见 [维护文档](MAINTENANCE.md)。
